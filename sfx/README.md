# Sonidos de taller (propios, sin licencia ni créditos)

Generados por código (`generar_sfx.py`), no son grabaciones reales. Libres de derechos: no hace falta dar créditos en los reels.
WAV 44,1 kHz, mono, pico -1 dBFS. Usar a volumen bajo-medio por debajo de la voz (la voz va a -14 LUFS).

URL: https://raw.githubusercontent.com/yumewelder/videos-reels/main/sfx/<nombre>.wav

| Archivo | Duración | Uso |
|---|---|---|
| arco_encendido_zap | 0,7 s | cebar el arco / inicio de soldadura |
| arco_soldadura_loop | 4,75 s (bucle) | soldando (arco eléctrico) |
| chispas | 2,2 s | salpicaduras, chispas |
| radial_corte | 3,2 s | amoladora cortando |
| martillo_yunque | 1,4 s | martillazo con resonancia metálica |
| golpe_metal_seco | 0,5 s | golpe seco, chapa, escuadra |
| picar_escoria | 1,3 s | picar escoria con la piqueta |
| gas_siseo_loop | 3,75 s (bucle) | gas, soplete, aire |
| taladro | 2,6 s | taladro con barrena |
| cepillo_alambre | 1,8 s | cepillar el cordón |
| chapa_cae_clang | 1,8 s | chapa que cae, golpe fuerte |
